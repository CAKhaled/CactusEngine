# Cactus Engine

Cactus Engine هو محرك ألعاب تعليمي **مفتوح المصدر**، يهدف إلى تسهيل تعلم برمجة وتطوير الألعاب، خصوصًا للمبتدئين والطلاب.

يوفر المشروع بيئة لتطوير ألعاب ثنائية وثلاثية الأبعاد (2D و3D)، بالإضافة إلى لغة برمجة خاصة بالمشروع باسم **KH**.

كون Cactus Engine مفتوح المصدر، يمكنك **استكشاف الكود المصدري وتعديله وتطويره وإضافة ميزات جديدة** بما يتناسب مع احتياجاتك، وفقًا لشروط الترخيص.

## المميزات

* دعم تطوير ألعاب 2D و3D.
* لغة برمجة خاصة بالمشروع باسم KH.
* صياغة برمجية بسيطة ومناسبة للمبتدئين.
* محرر لتطوير وتجربة الألعاب.
* دعم العناصر والمتجهات ثلاثية الأبعاد.
* دعم الإضاءة والمشاهد ثلاثية الأبعاد.
* دعم تحميل الصور والخامات.
* دعم التعامل مع الماوس.
* تنفيذ الأكواد مع كل إطار باستخدام `كل_فريم`.
* مجموعة من الدوال الرياضية المفيدة في تطوير الألعاب.
* مكونات تعليمية مرتبطة بالذكاء الاصطناعي والشبكات العصبية.

## المتطلبات

قبل تشغيل Cactus Engine، تأكد من توفر:

* Python 3
* المكتبات المطلوبة للمشروع.

## التثبيت

قم باستنساخ المستودع باستخدام:

```bash
git clone https://github.com/CAKhaled/CactusEngine.git
```

ثم انتقل إلى مجلد المشروع:

```bash
cd CactusEngine
```

## تشغيل المحرك

لتشغيل Cactus Engine، استخدم الأمر:

```bash
py main.py
```

أو:

```bash
python main.py
```

سيؤدي ذلك إلى تشغيل المحرك وفتح واجهته.

## لغة KH

يستخدم Cactus Engine لغة برمجة خاصة بالمشروع باسم **KH**.

تم تصميم اللغة لتسهيل تعلم البرمجة وتطوير الألعاب، مع التركيز على جعل كتابة الأكواد وفهمها أكثر وضوحًا للمبتدئين.

تستخدم ملفات KH الامتداد:

```text
.kh
```

مثال بسيط:

```kh
اطبع "مرحبا"
```

## توثيق لغة KH

للتعرف على لغة KH بشكل كامل، ومعرفة الصياغة البرمجية والأوامر والخصائص والأمثلة، يمكنك زيارة التوثيق الرسمي:
